# Alex's Tracker

A browser-based tracker for the Fortnite Sprites collection. Track which sprites you own and have mastered, filter and sort your collection, export collection images, and share view-only collection links.

## Features
- Collection and mastery tracking with progress bars
- Search and filter by season, variant, rarity, and status
- Sort by variant, sprite, rarity, or alphabetical
- Export collection images (collected, missing, unmastered, mastered, trade card)
- Copy trade lists as text or grid
- Backup and restore via JSON
- Share view-only collection links
- Per-sprite badge tracking (natural/won)
- Auto-updating sprite list from spritechecklist.org
